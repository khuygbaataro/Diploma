# Туршилтын сайт дээр 0.3.0 хувилбарыг суулгах заавар

Энэ заавар нь туршилтын Moodle сайт дээр plugin, ботыг 0.3.0 болгож, зохиомол оюутантай демо хичээл дээр багшийн тайланг туршиж үзэхэд зориулагдсан.

Зааварт дараах үгсийг өөрийн утгаар солино. Жинхэнэ утгыг хаана ч нийтэд бичихгүй.

| Зааварт | Юугаар солих вэ |
| --- | --- |
| `ТАНЫ-ДОМЭЙН` | Moodle сайтын хаяг, жишээ нь `moodle.example.mn` |
| `SERVER-IP` | Серверийн IP хаяг |
| `ХЭРЭГЛЭГЧ` | Сервер рүү SSH-ээр ордог нэр |
| `ТОКЕН` | Ботын Moodle токен (5-р алхамд гарна) |
| `НУУЦ-ҮГ` | Демо багшийн нууц үг (6-р алхамд гарна) |
| `/var/www/moodle` | Сервер дээрх Moodle-ийн хавтас (`config.php` байгаа газар) |

## 1. Эхлэхээс өмнө

- Moodle 5.0, Ubuntu сервер, `sudo` эрхтэй SSH хандалт хэрэгтэй.
- Сайтын мэдээллийн санг нөөцөлж авна. Туршилтын сайт ч гэсэн нөөцтэй байвал буцаахад амар.
- Moodle-ийн стандарт лог асаалттай байх ёстой: Site administration → Plugins → Logging → Manage log stores → **Standard log**. Унтраалттай бол тайланд «зарцуулсан цаг» гарахгүй.

## 2. Суулгах багцуудыг бэлдэх

Хоёр zip файл хэрэгтэй: `local_darimaa-0.3.0.zip` (plugin) ба `darimaa-bot-0.3.0.zip` (бот). Доорх хоёр аргын аль нэгээр авна.

**А. Өөрийн компьютер дээр үүсгэх.** Репозиторийн хавтаст:

```bash
python tools/package.py
```

Хоёр файл `dist/` хавтаст гарна.

**Б. GitHub-аас татах.** Репозиторийн **Actions** → **Package** → **Run workflow** дарна. Ажиллаж дууссаны дараа тухайн ажлын хуудасны **Artifacts** хэсгээс `local_darimaa`, `darimaa-bot` хоёрыг татна. GitHub татсан файлыг дахин zip-д хийдэг тул нэг удаа задалж доторх zip-ийг гаргана.

Plugin-ий zip доторх хавтас `darimaa/`, ботын zip доторх хавтас `darimaa-bot/` байна. Нэрийг нь өөрчлөхгүй.

## 3. Plugin-ийг шинэчлэх (0.1.0 → 0.3.0)

1. Moodle-д админаар нэвтэрнэ.
2. Site administration → Plugins → **Install plugins** руу орно.
3. `local_darimaa-0.3.0.zip` файлыг оруулаад **Install plugin from the ZIP file** дарна.
4. Шалгалтын хуудсанд **Continue**, дараа нь **Upgrade Moodle database now** дарна.
5. Шинэ тохиргооны хуудас гарвал **Save changes** дарна.
6. Site administration → Plugins → Plugins overview хэсгээс «Teacher & Student Assistant» 0.3.0 болсныг шалгана.

Хуучин хувилбарын өгөгдөл устахгүй. Шинэчлэх үед Messenger холболтын хүснэгт болон «Darimaa bot» нэртэй web service шинээр үүснэ.

Вэбээр оруулж болохгүй бол сервер дээр гараар хийнэ:

```bash
scp local_darimaa-0.3.0.zip ХЭРЭГЛЭГЧ@SERVER-IP:~/
```

```bash
cd /var/www/moodle/local
sudo rm -rf darimaa
sudo unzip ~/local_darimaa-0.3.0.zip
sudo chown -R www-data:www-data darimaa
sudo -u www-data php /var/www/moodle/admin/cli/upgrade.php
```

## 4. Оюутны кодын талбарыг сонгох

Site administration → Plugins → Local plugins → **Teacher & Student Assistant** руу орно.

- **Student code field**: оюутны код Moodle-ийн аль талбарт байгааг сонгоно. Сонголт нь username, ID number, эсвэл нэмэлт (custom) талбар. Демо хичээлийн оюутны код username дээр байгаа тул туршихдаа **username** хэвээр үлдээнэ.
- **Session timeout (minutes)**: 30 хэвээр үлдээнэ. Оюутны хоёр үйлдлийн хоорондох завсар үүнээс богино бол хичээлд зарцуулсан цагт тооцно.

## 5. Ботын токен авах

Сервер дээр, Moodle-ийн хавтаст:

```bash
cd /var/www/moodle
sudo -u www-data php local/darimaa/cli/setup_bot.php --iprestriction=SERVER-IP
```

Скрипт Web services-ийг асааж, ботын данс, эрх, токеныг үүсгэнэ. Төгсгөлд нь хоёр мөр гарна:

```
MOODLE_URL=https://ТАНЫ-ДОМЭЙН
MOODLE_TOKEN=ТОКЕН
```

Энэ хоёр мөрийг ботын `.env` файлд хийнэ. Токеныг чат, имэйл, GitHub-д бичихгүй. Өмнө нь токен авсан бол скрипт хуучин токеноо дахин харуулна.

## 6. Демо хичээл үүсгэх

Демо скриптүүд plugin-ий багцад ордоггүй. Репозиторийн `tools/demo` хавтсыг сервер рүү хуулна:

```bash
scp -r tools/demo ХЭРЭГЛЭГЧ@SERVER-IP:~/darimaa-demo
```

Сервер дээр эхлээд юу хийхийг нь харна. `--confirm` бичээгүй үед скрипт юу ч өөрчлөхгүй:

```bash
sudo -u www-data php ~/darimaa-demo/create_demo_course.php --config=/var/www/moodle/config.php
```

Эхний мөрөнд сайтын хаяг гарна. Зөв сайт мөн бол үүсгэнэ:

```bash
sudo -u www-data php ~/darimaa-demo/create_demo_course.php --config=/var/www/moodle/config.php --confirm
```

Төгсгөлд демо багшийн нэр, нууц үг гарна:

```
username: demo26teacher
password: НУУЦ-ҮГ
```

Нууц үг **ганцхан энэ удаа** гарна, хаана ч хадгалагдахгүй. Тэр дор нь тэмдэглэж авна.

Үүссэн зүйлс:

- «Демо хичээл: Биологи 101» (богино нэр `DEMO-DARIMAA`), 8 долоо хоногийн өмнө эхэлсэн.
- 1 багш (`demo26teacher`), 30 оюутан (`demo26b001` … `demo26b030`), 2 бүлэг.
- 3 даалгавар: хоёрынх нь хугацаа өнгөрсөн, зарим оюутан илгээгээгүй. Нэг нь хугацаа болоогүй.
- 2 сорил, тус бүр 9 асуулт, 3 сэдэв. 1-р сорилын сэдэв нь сорилын дүнгийн хэсэг (grade item), 2-р сорилынх нь асуултын ангилал.
- Сорилыг ихэнх оюутан өгсөн: сайн оюутан, нэг сэдэвт сул оюутан, бүхэлдээ сул оюутан, хоёр удаа өгсөн оюутан, огт өгөөгүй оюутан бий.
- 5 оюутан хичээлд огт ороогүй, 6 оюутан 8–20 хоногийн өмнө орсон, бусад нь сүүлийн долоо хоногт орсон.
- Хичээлд зарцуулсан цаг нэг цаг хүрэхгүйгээс 12 цаг орчим хүртэл байна.

Бүх нэр, дүн зохиомол. Оюутнууд нэвтэрч чадахгүй, имэйл нь `example.invalid` хаягтай тул Moodle тэдэнд имэйл явуулахгүй. Скрипт сайтын бусад хэрэглэгч, хичээлд хүрэхгүй.

Скриптийг хоёр дахь удаа ажиллуулбал «демо хичээл аль хэдийн байна» гээд юу ч өөрчлөхгүй зогсоно.

Бүх зүйл зөв үүссэнийг шалгана:

```bash
sudo -u www-data php ~/darimaa-demo/check_demo_course.php --config=/var/www/moodle/config.php
```

Мөр бүр `OK` гэж эхэлж, төгсгөлд нь `All checks passed.` гарах ёстой.

## 7. Ботыг суулгах, шинэчлэх

**Бот өмнө нь суулгаагүй бол** `bot/README.md`-ийн 2, 3, 4-р хэсгийг дагана.

**Бот суулгасан байгаа бол** шинэ файлуудыг хуучны дээр хуулна. `.env` файл zip-д байдаггүй тул хэвээр үлдэнэ.

```bash
scp darimaa-bot-0.3.0.zip ХЭРЭГЛЭГЧ@SERVER-IP:~/
```

```bash
sudo unzip -o ~/darimaa-bot-0.3.0.zip -d /opt/
sudo chown -R darimaa:darimaa /opt/darimaa-bot
sudo /opt/darimaa-bot/venv/bin/pip install -r /opt/darimaa-bot/requirements.txt
sudo systemctl restart darimaa-bot
curl http://127.0.0.1:8100/healthz
```

Сүүлийн мөр `{"ok":true}` гэж хариулах ёстой.

Хүсвэл `/opt/darimaa-bot/.env` файлд дараах хоёр мөрийг нэмнэ. Нэмэхгүй бол 60 ба 30 гэж үзнэ.

```
WEAK_TOPIC_BELOW=60
EXAM_POINTS=30
```

Ботын 0.2.2-оос өмнөх хувилбар ажиллаж байсан бол Page-ийн access token-оо Meta дээр шинээр үүсгээд `.env`-д солино. Хуучин хувилбар токеныг логт бичдэг байсан.

## 8. Демо багшаар чатаар турших

1. Moodle-д `demo26teacher` нэр, 6-р алхамд гарсан нууц үгээр нэвтэрнэ.
2. Preferences → **Messenger connection** руу ороод **Connect Messenger** дарна. 8 тэмдэгттэй код гарна.
3. Тэр кодыг Page руу Messenger-ээр бичнэ. Бот «Боллоо, Багш!» гэж хариулна.
4. Дараахыг дарж, эсвэл бичиж үзнэ:

| Юу хийх вэ | Юу гарах ёстой вэ |
| --- | --- |
| «Идэвхгүй оюутан» товч | Демо хичээлийг үүсгэсэн өдөр 11 идэвхгүй оюутан: 5 нь «огт ороогүй», 6 нь 8–20 хоногийн өмнө орсон. Мөр бүрд код, нэр, цаг, илгээгээгүй даалгаврын тоо. Өдөр өнгөрөх тусам идэвхгүй оюутны тоо нэмэгдэнэ. |
| «Сорилын дүн» товч, дараа нь 1-р сорил | 23 оюутан өгсөн, 7 оюутан өгөөгүй. 3 сэдэв сулаас нь эрэмбэлэгдэнэ. Сул сэдэвтэй оюутнууд шалгалтын ойролцоо оноотойгоо гарна. |
| «Сорилын дүн» товч, дараа нь 2-р сорил | 21 оюутан өгсөн, 9 оюутан өгөөгүй. Сэдвүүд нь асуултын ангиллаар гарна. |
| «сул сэдэв» гэж бичих | «Сорилын дүн» товчтой адил. |
| «Илгээгээгүй» товч | Илгээгээгүй оюутантай даалгаврууд. |

Анхаарах зүйлс:

- Meta дээрх app туршилтын горимд байвал бот зөвхөн app-д эрхтэй (admin, developer, tester) хүнд хариулна.
- «Илгээгээгүй» цэсээс «Тийм, явуул» дарвал демо оюутнуудад Moodle-ийн мэдэгдэл очно. Тэд зохиомол хүмүүс, имэйл нь явахгүй тул аюулгүй. Гэхдээ жинхэнэ хичээл дээр дарахаас болгоомжилно.
- «Идэвхгүй оюутан», «Сорилын дүн» хоёр зөвхөн мэдээлэл харуулна. Оюутанд юу ч явуулахгүй.

## 9. Демо өгөгдлийг устгах

```bash
sudo -u www-data php ~/darimaa-demo/create_demo_course.php --config=/var/www/moodle/config.php --delete --confirm
```

Скрипт зөвхөн өөрийн үүсгэсэн хичээл, 31 хэрэглэгчийг устгана. Устсаныг шалгана:

```bash
sudo -u www-data php ~/darimaa-demo/check_demo_course.php --config=/var/www/moodle/config.php --gone
```

Төгсгөлд нь `The demo data is gone.` гарах ёстой. Үүний дараа демо хичээлийг дахин үүсгэж болно.

Moodle хэрэглэгчийг бүр мөсөн арилгадаггүй, «устгасан» гэж тэмдэглэдэг. Мөн хичээл үүсгэсэн, устгасан тухай Moodle-ийн өөрийн логийн бичлэг үлдэнэ. Энэ бол Moodle-ийн ердийн ажиллагаа.

## 10. Асуудал гарвал

- **Скрипт `Give the path of Moodle's config.php` гэвэл** `--config=` хойно `config.php` файлын бүтэн замыг бичнэ.
- **`Cannot create the demo course` гэвэл** демо хичээл аль хэдийн байна, эсвэл `demo26…` нэртэй хэрэглэгч байна. Эхлээд 9-р алхмаар устгана.
- **Шалгах скрипт `the time estimate is available` дээр `WRONG` гэвэл** стандарт лог унтраалттай байна (1-р алхам).
- **Шалгах скрипт `The plugin local_darimaa 0.3.0 or later is not installed` гэвэл** 3-р алхмыг дуусгаагүй байна.
- **Бот «Танд үүнийг хийх эрх алга» гэвэл** Messenger-ээ демо багшийн дансаар холбосон эсэхийг шалгана.
- **Бот хариулахгүй бол** `sudo journalctl -u darimaa-bot -f` гэж логийг харна. Логт токен, оюутны нэр бичигдэхгүй.
- Ботын бусад асуудлыг `bot/README.md`-ийн «Асуудал гарвал» хэсгээс харна.
